MY FREEDOM PLAN V4.7 PWA

This version uses the five real illustration assets as the visual background for Home, Money, Invest, Life and More.
The UI cards, charts, navigation and data remain HTML/CSS/JavaScript so they can be edited and used normally.

Storage: localStorage on the device.
Backup: More > Backup / Restore > Export Backup.
Install on iPhone: open the GitHub Pages URL in Safari > Share > Add to Home Screen.

This is a personal planning tool, not financial advice. Projection uses an illustrative 7% annual return assumption and is not guaranteed.


V4.7 simplification: the financial UI now focuses on only three buckets — Investment, Emergency Reserve, and Happy Money (travel & shopping). Income, salary, expenses, budgets, shopping fund and money-available screens are no longer presented in the main interface.


V4.8 change: Investment starts at zero. ETF rows show zero until a contribution is added. Percentages are recalculated from actual values; demo gains were removed. New ETF symbols can be added from Add Contribution.
